PoeXD Extension 使用教程

PoeXD 会在《流放之路》PoE 1／PoE 2 官方交易市集旁加上一条可折叠的侧边工具栏，集中监听实时搜索、快速套用词缀与 T 阶、整理书签与 PoB 购物清单，并将国际服市集翻译成中文。

支持：PoE 1 / PoE 2 官方市集（国际服・腾讯服・台服） 环境：Edge / Chrome / Brave 界面：简体中文 / 繁體中文 / English 存储：纯本地零上传

01 / INSTALLATION

安装

商店版会随版本发布自动更新，日常游玩建议优先从 Edge 或 Chrome 商店安装（国内环境推荐使用 Edge 商店，无需额外代理即可直连）；Firefox 目前暂未提供支持。

浏览器安装步骤
Microsoft Edge前往 Microsoft Edge 外接程序商店 ↗，点击「获取」即可安装并自动更新。
Chrome、Brave 等 Chromium 浏览器前往 Chrome 应用商店 ↗，点击「添加至 Chrome」即可自动更新。
  1. 到 GitHub Releases ↗ 下载最新版的 chromium.zip，解压到固定文件夹（日后不要删除或移动）。
  2. 在地址栏输入 edge://extensions/（Chrome 为 chrome://extensions/），打开「开发人员模式」。
  3. 点击「加载解压缩的扩展」，选择刚才解压的文件夹即可完成加载。

手动安装版不会自动更新，有新版本时需要重新下载并覆盖同一个文件夹，再到扩展管理页点「重新加载」。

02 / FIRST RUN

第一次使用

  1. 打开 官方交易网站 ↗（腾讯服、台服同样支持），页面左侧会出现 PoeXD 侧边工具栏（可在设置的「面板位置」改到右侧）；收起时只保留一个可上下拖动的 PoeXD 标志。
  2. 首次安装展开侧边栏会自动开始引导；工具栏标签依次对应书签、历史记录、常用词缀群组、PoB 购物清单、置顶物品、搜索结果看板与线上搜索主控台。
  3. 在交易页点击浏览器右上角的 PoeXD 图标可直接切换展开／收起侧边栏；各项功能模块可在侧边栏的「系统设置 → 侧边栏模块」中单独开关（非交易页点击图标则提供各服市集快捷入口）。
03 / LIVE SEARCH CONSOLE

线上搜索主控台

在单个标签页中集中监听多组实时搜索（Live Search），断线自动重连，有新物品上架时实时显示，并支持官方提示音与后台桌面通知。

  1. 打开线上搜索主控台，可「从书签挑选」要监听的搜索，或「输入搜索网址」直接粘贴交易网站的搜索链接。
  2. 连接会按书签文件夹分组并显示命中数，可批量启用或停止；每条结果卡片会标示来源连接，点击来源标签或单个连接即可只看该组结果，也能一键清空结果区而不中断监听。
  3. 在主控台设置中可直接调整官方通知音效、音量或上传自定义音频文件（上限 1 MB），并可开启「后台桌面通知」（每个监听项独立一张通知卡，短时间多条自动合并，点击即可切回主控台）。
  4. 主控台会实时显示官方 API 速率状态，避免监听过多而被暂时限流；重开浏览器可一键恢复上次的连接组合。

主控台标签页需要保持打开才会持续监听。PoeXD 已防止该标签页被浏览器自动休眠释放，但电脑进入睡眠时连接仍会中断，唤醒后会自动重连。

04 / STAT GROUPS & PREVIEW

常用词缀群组与搜索预览

把常用条件（例如「最大生命＋总元素抗性」）保存为群组，之后直接叠加到当前搜索，不会覆盖已经设置好的其他筛选。

建立与应用群组

  1. 在工具栏打开「常用词缀群组」，新建群组并加入需要的词缀与数值下限。
  2. 在任意搜索页面点击群组即可叠加到当前筛选；点错了可以一键撤销。
  3. 群组支持原地重命名、分享码与备份文件导入／导出（导入前提供勾选预览），方便和朋友交流或换电脑时迁移。

搜索预览

点击书签或历史记录的名称会先打开搜索预览（名称旁的箭头才是直接打开搜索），可以看到背后的实际条件，在预览窗口微调词缀数值，或只勾选其中几条叠加进当前搜索。

05 / AFFIX SELECTOR & TIERS

词缀筛选与 T 阶

词缀选择器

  1. 在官方筛选群组旁打开词缀选择器，从标题栏切换物品类别（含「最近使用」，并可同步套用到官方物品种类），也能用「物等」区间过滤可出现的词缀。
  2. 按前缀／后缀与词缀来源分类浏览（支持全部展开／收起与全选匹配项），勾选需要的词缀加入右侧「待应用清单」。
  3. 确认后一次批量写入官方筛选器，无需一条一条手动输入关键词。

T 阶快捷按钮

筛选栏旁的 T 按钮可直接点击单个阶级或复选阶级范围、点击数值快速填入；同一词缀在该物品类别有多种来源时，可在左侧切换词缀分组。支持 PoE 1 追忆、穿越、古灵与异界基底词，以及 PoE 2 的碑牌、换界石、范围珠宝与圣域词缀；词缀也可拖拽排序或移至其他筛选群组。

06 / RESULT ENHANCEMENTS

搜索结果增强

功能说明
价格换算与排序按 poe.ninja 汇率换算不同通货标价，并支持按换算后的价格排序（仅国际服）。
结果词缀高亮自动框选标出符合你筛选条件的词缀与前后缀阶级（如 P2、S1）。
结果词缀快筛鼠标移到结果中的词缀，右侧出现「+和／+不」按钮，可快速加入筛选（仅填入词缀，不会自动重搜）。
复制 PoB 物品文本鼠标移到结果卡片左上角，点击 PoB 按钮即可复制英文物品文本粘贴进 Path of Building；国服与台服会自动转为英文。
PoEDB 链接卡片左上角的 DB 按钮可直接打开该装备基底的 PoEDB 页面。
符文覆盖试算（PoE 2）试算符文覆盖后的 DPS／防御数值，并支持按试算结果排序。
07 / RESULT BOARD

搜索结果看板

在普通搜索页把当前拉取的结果集中到侧边栏（从侧边栏标签或官方结果数旁的「看板」按钮打开），默认不会改动官方结果列表，也可手动开启同步过滤直接筛选官方列表。

  1. 物品列表与独立词缀筛选：按关键词、价格区间、隐藏已售出与只看可直购筛选并排序；可展开「必含独立词缀筛选」拆解结果中的单词／复合词缀（支持 T1、T1–T2 等阶级与分裂／基底／工艺分类），并可一键同步过滤左侧官方结果列，点一下即可滚动定位并高亮官方结果列。
  2. 卖家列表与仓库分组：按可直购件数与换算总价排序，找出能在同一间藏身处一次买齐多件的卖家，并按仓库页分组标出格位坐标。
  3. 仓库搜索 regex：勾选同一卖家要买的物品后显示小计，一键复制 regex 粘贴进对方仓库搜索框，同时高亮所有目标物品（无法区分时会给出提示警告）。
  4. 批量加载与自动刷新：通过官方「加载更多」逐批（可记忆每次条数）或一次加载全部（上限 100 条）；前往藏身处链接过期时会自动刷新后再前往。

搜索结果看板不保存历史数据，切换下一个搜索就会刷新；想长期留下来慢慢比价的装备请使用「置顶物品」。

08 / PINNED ITEMS

置顶物品

  • 鼠标移到搜索结果卡片左上角点击置顶，就能把物品连同标价、金币手续费、卖家与上架时间保存到侧边栏，以官方样式卡片随时展开比价。
  • 普通搜索、实时搜索与线上搜索主控台均可使用，并支持切换「显示所有赛季」。
  • 支持搜索筛选、排序（自定义顺序、最新置顶、价格高低）、拖拽调整顺序或拖出取消置顶。
  • 一口价物品可直接点击前往藏身处，已卖出的物品会标示「已售出」；每个游戏版本最多在本地浏览器保存 50 条。
09 / POB SHOPPING LIST

PoB 购物清单

  1. 在工具栏打开「PoB 购物清单」，粘贴 Path of Building 导出代码，或 poe.ninja、pobb.in、pastebin 分享链接。
  2. 默认以「装备栏」纸娃娃视图呈现角色装备、武器组切换（I / II）、药剂、星团与珠宝、插槽连线与宝石图标（支持 PoE 1 / PoE 2，可切换为「列表」视图）；可同时保存多份 BD，并在多套装备或技能组间实时切换。
  3. 可针对整份 BD 调整「全局搜索设置」（词缀数值下限比例、连线条件、稀有装改按类别＋防御类型搜索、防御下限与默认改用总和词缀），或在单件预览微调条件、放宽 10%（-10%）后一键搜索、加入书签、送进线上搜索主控台，或将当前页面搜索存回该栏位。

从 pobb.in、pastebin 导入需要额外授权访问该网站。代码只保存在你的浏览器本地，不会上传。开启市集汉化并授权 pobb.in 后，pobb.in 分享页也会自动显示中文。

10 / BOOKMARKS & HISTORY

书签与历史记录

  • 以树状文件夹收纳搜索，支持自定义文件夹图标与颜色、拖拽排序、自定义封面图与悬停预览。
  • 当前页面对应的书签会自动高亮显示；也能用当前筛选条件覆盖已有书签。
  • 书签会自动套用当前的服务器与赛季设置，换赛季无需全部重建。
  • 每次提交的搜索都会自动记录在历史记录标签页中，方便回溯。
  • 支持与 TFT Trade Extension 互相导入、导出书签，导入前会先预览差异。

书签文件夹也会同步成为「线上搜索主控台」的分组单位；建议按开荒、毕业装备或通货等用途建好文件夹，之后能直接批量启停整组实时搜索。

11 / TRADE LOCALIZATION

市集汉化

将国际服英文市集的界面、筛选器、提示信息与搜索结果显示为中文。仅改变页面显示，不会改动实际提交的搜索参数。

  1. 在 PoeXD 设置的「语言与市集汉化」中，将语言设为简体中文（采用腾讯服官方用语）或繁体中文（采用台服官方用语）。
  2. 开启「市集汉化」，刷新交易页面即可生效；新赛季或游戏更新时可在设置点击「立即更新」手动拉取最新汉化数据。
  3. 想同时看到英文原文时，可开启「筛选下拉菜单」中英对照（输入中文或英文都能搜到），以及「搜索结果词缀」在翻译词缀下方附上淡色英文原文。

12 / SETTINGS & THEMES

设置、外观主题与快捷键

  • 单页可搜索设置与模块开关：通过顶部分类导航或搜索快速找到设置项，可单独开关侧边栏与页面增强模块，并备份／还原或重置（同时包含 PoE 1 与 PoE 2 设置）。
  • 11 款内置主题与自定义配色：内置深色与浅色共 11 款主题，也可在「自定义」调整背景色、表面色、文字色、主色、危险色与 4 种圆角风格，提供实时组件预览并支持复制／导入 JSON 分享配色。
  • 布局与引导：直接拖动侧边栏内侧边缘即可调整宽度，并支持切换左右侧、界面缩放比例、使用引导与「在页面上指出」标示。
  • 搜索与快捷键：物品名称与筛选栏支持模糊搜索（自动加 ~）、自定义聚焦／清除快捷键（Backspace 清除、Esc 取消），以及将标签页标题替换为当前搜索的物品名称。
  • 扩展界面提供简体中文、繁体中文与英文；词缀数据覆盖官方交易网站 11 种语言。
13 / FAQ

常见问题

我的数据会被上传吗？

不会。PoeXD 没有服务器，也没有统计分析或追踪代码，所有数据都保存在你的浏览器本地。详见 隐私政策 ↗。

为什么价格换算没有出现？

价格数据来自 poe.ninja，仅提供国际服；国服（腾讯服）与台服目前不支持价格换算。

工具栏没有出现怎么办？

请确认当前页面为官方交易网站，并在浏览器扩展管理页确认 PoeXD 已启用后刷新页面。若仍未出现，欢迎到 GitHub 提交 Issue 反馈。

哪里可以查看更新内容、反馈问题？

更新内容整理在 Releases ↗；功能建议或问题反馈请提交 Issue ↗，安全问题请依 SECURITY.md ↗ 私下联系。
