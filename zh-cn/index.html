01 / FLAGSHIP PROJECT

代表作品：PoeXD Extension

已上架 Microsoft Edge 外接程序与 Chrome Web Store，直接集成在官方交易网页旁，无需跳转外部网站。

模块化设计、本地存储与跨工具整合规格

不想被迫接受一整包臃肿插件，因此把每个功能拆成可独立开关的模块；侧边工作台可停靠左侧或右侧，并自定义界面缩放比例与聚焦快捷键。

  • 支持范围同时支持 PoE 1／PoE 2 官方交易市集，覆盖国际服、腾讯服（国服）与台服；界面提供简体中文、繁体中文与英文。
  • 跨工具互通支持导入 Path of Building 代码、poe.ninja／pobb.in／pastebin 链接，并可与 TFT Trade 互相导入导出书签。
  • 安装与发布商店版会随更新自动推送，也可在 GitHub Releases 下载 chromium.zip 手动加载已解压的扩展程序。
  • 技术架构使用 WXT 构建浏览器扩展架构，搭配 Vue 3 与 TypeScript 开发，并通过 Vitest 与 Playwright 覆盖测试。

TECH STACKTypeScript · Vue 3 · WXT · Tailwind CSS · Vitest · Playwright

DESIGN & PRIVACY STANDARDS

做这个工具的三条底线

01 / LOCAL-FIRST

数据留在你自己的浏览器

无需注册账号，也没有自建后端服务器、统计分析或追踪脚本；书签、词缀群组、PoB 清单与快捷键设置全都只保存在本地浏览器里。

02 / MIT OPEN SOURCE

MIT 协议完全开源

扩展源码与词缀数据处理脚本均公开在 GitHub，任何人都能审查权限申请与代码行为，也欢迎提交 Issue 反馈问题或讨论需求。

03 / SEASONAL UPDATES

随游戏赛季与市集改版更新

每逢 PoE 1 或 PoE 2 新赛季、新词缀实装或官方交易网站调整布局时同步维护，详细更新日志都会整理在 GitHub Releases。
